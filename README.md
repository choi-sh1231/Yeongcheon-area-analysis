# 🏛️ 영천의 미학: 영천시 1km 격자 기반 복합 취약 지역 도출 및 인프라 사각지대 분석

영천의 미학은 영천시의 고령화 인구, 생활용 지하수, 소방·의료·버스정류장 위치 데이터를 기반으로 지역별 인프라 격차 및 사회적 고립 문제를 분석하고, 복합 취약 지역 파악 후 개선 우선순위 구역을 제안하는 프로젝트입니다.

## 🎯 프로젝트 목표

- 고령 인구 분포, 생활용 지하수 사용 분포, 의료·소방·버스정류장 접근성을 1km 격자 단위로 시각화
- 격자별 취약 지표 도출 후 지표 간 상관관계 파악
- 엔트로피 기법 + AHP 하이브리드 가중치 모델로 복합 취약 지수 산출 및 시각화
- K-Means 군집화를 통한 취약 유형화 후 GPT-4o-mini 연동 정책 리포트 자동 생성
- Streamlit 대시보드를 통한 취약 지역 유형별 정책 제안

## 📚 데이터 및 분석 방법론

총 7종의 csv, shp 파일을 수집 및 전처리하여 분석에 활용하였습니다.

- 영천시 1km 격자 데이터
- 영천시 1km 인구 데이터
- 영천시 1km 주택 데이터
- 영천시 1km 생활용 지하수 데이터
- 영천시 소방시설 데이터
- 영천시 병원시설 데이터 (병원·응급실·보건소)
- 영천시 버스정류장 데이터

사용 라이브러리: GeoPandas, Pandas, NumPy, Matplotlib, ckDTree, OSMnx, NetworkX

### 핵심 방법론

**영천시 맞춤 우회계수 산출 (선형회귀)**
- Tmap API로 실제 도보거리를 구하지 못하는 데이터 다수 발생 (영천시 산지·농로 특성)
- Tmap API로 구한 실제 도보거리와 유클리드 직선거리를 선형회귀로 분석
- 상하위 5% 이상치 제거 후 교차검증으로 타당성 확보
- **영천시 최적 우회계수 = 2.07** 도출

**히트맵 분석**
- 대중교통·소방시설·의료시설 접근성 취약 지수 시각화
- 스무딩 기법으로 격자 이상치 처리 (주변 격자 평균값으로 대체)

**복합 취약 지수 모델링**
- 엔트로피(Entropy) 기법 + 계층화 분석법(AHP) 하이브리드 가중치 산정
- K-Means(K=5) 군집화로 취약 유형 구분
- Safe Zone 컷오프 알고리즘 적용

**GPT-4o-mini 연동 정책 리포트 자동화**
- 복합 취약 지수 분석 결과를 LLM이 자동으로 유형별 정책 리포트로 생성
- Streamlit 인터랙티브 대시보드로 결과 시각화 및 제공

## 📊 주요 분석 결과

- 격자별 고령화 지수·생활용 지하수 취약 지수·인프라 접근성 지수 산출
- 영천시 격자별 소방시설 접근성 (자동차 접근 시간 기준) 히트맵
- 영천시 격자별 의료시설 접근성 (자동차 접근 시간 기준) 히트맵
- 영천시 격자별 대중교통 접근성 (도보 접근 시간 기준) 히트맵 + 맞춤 우회계수 적용
- 복합 취약 지수 기반 종합 취약 핫스팟 구축
- 군집화를 통한 취약 유형 구분 및 유형별 정책 제안

## 🛠️ 정책 제안

단순한 취약 지역 파악에 그치지 않고, 복합 취약 지수와 유형별 맞춤 정책을 제안합니다.

- 의료 접근성 취약 구역: 찾아가는 의료 서비스·순회 진료 우선 배치
- 교통 취약 구역: 수요 응답형 교통(DRT) 도입 및 버스 노선 재편
- 소방 취약 구역: 소방차 진입로 정비 및 의용소방대 거점 확충
- 복합 취약 구역: 다부처 협력 통합 지원 우선 대상 선정
